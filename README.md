Репозиторий содержит лабораторные работы по дисциплине «Компьютерная графика».

В рамках лабораторных работ разработана интерактивная 3D-модель промышленного (фабричного) манипулятора. Реализованы вертексный и фрагментный шейдеры для отображения 3D-объектов, управление камерой, настройка освещения и анимация отдельных элементов манипулятора.

Назначение проекта: Практическое освоение основ компьютерной графики, работы с 3D-моделями, шейдерами, освещением и интерактивным управлением объектами в трёхмерной сцене.
